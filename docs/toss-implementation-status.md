## 실행 방법

```bash
# 자동 테스트: 외부 네트워크 금지, localhost 가짜 서버만 허용
.venv/bin/python -m pytest -q

# 복사본에서 핵심 방어 로직을 제거해 테스트의 검출 능력 확인
.venv/bin/python scripts/check_safety_mutations.py

# 실제 계좌 조회: 사용자가 환경변수를 설정한 후 별도로 실행
# TOSS_CLIENT_ID / TOSS_CLIENT_SECRET / TOSS_ACCOUNT_SEQ
.venv/bin/python broker_cli.py sync

# 저장된 조회 데이터를 사용한 주문 미전송 미리보기
.venv/bin/python broker_cli.py preview --budget-usd 1000
```

`preview`의 budget은 투자 권유가 아닌 명시적인 목표 포트폴리오 규모 입력이다.
최근 확정 신호, 최신 일봉, 30초 이내 조회·시세가 없으면 차단된다.
`sync`는 daily_job이나 UI 시작 시 자동 실행되지 않는다.
토큰을 명령줄 인자로 전달하거나 저장소에 붙여넣지 않는다.

## 검증 중 확인한 로컬 DB 영향

최초 UI 통합 테스트가 Streamlit의 `__main__` 변경을 남겨 뒤의 spawn 테스트가
UI 스크립트를 불러오는 격리 문제가 있었다. 원래 모듈을 복원하도록 수정한 뒤
최종 전체 119개 테스트가 통과했다. 이 과정에서 기존
`data/inflation_compass.db`에 추가형 초기화 스키마(`signal_provenance` 등)가 적용된
것을 확인했다. 기존 DB에는 주문 엔진 테이블이 생성되지 않았으며 실제 API
요청/주문은 실행하지 않았다. 원본 DB를 삭제하거나 이전 파일로 덮어쓰지 않았다.

최종 자동 검증 집계: [toss-test-results.json](toss-test-results.json).
